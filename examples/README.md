# Complete first-run example

The files in this folder describe one cylinder case, from surface preparation
to solver output. See the [walkthrough](../doc/user/getting-started.md) for copying
them into a run folder, simulation, analysis, and regeneration commands.

| File | Purpose |
| :--- | :--- |
| [first-run.stl](first-run.stl) | Original triangulated cylinder, coordinates in millimetres |
| [first-run.pr2](first-run.pr2) | Geometry-tool profile: input surface, seed, grid, iolets, and timing |
| [first-run.gmy](first-run.gmy) | Prepared voxel geometry generated from that STL/profile |
| [first-run.xml](first-run.xml) | Matching version 6 solver input, with field output and checkpoints enabled |

The surface was constructed with VTK using 64 circumferential segments and
16 axial intervals, triangulated, and saved as binary STL. Axial segmentation
lets the geometry tool clip near the inlet/outlet planes without interpolating
across triangles that span the cylinder's full length. Its radius is 0.5 mm
and length 4 mm. The profile clips the inlet and outlet at `z = -1.5` and
`+1.5` mm, uses 0.1 mm voxels and a 0.0001 s timestep,
and runs 200 timesteps. The profile stores mean pressures of 0.01 and 0 mmHg; the ready XML uses
the equivalent 1.333223874 and 0 Pa. These
are example settings, not a validated haemodynamic benchmark.

The prepared GMY was generated by `hlb-gmy-cli first-run.pr2`; the ready XML
uses the generated origin, voxel size, and iolets, with monitoring and output
requests added. The surface extends beyond the clipping planes, so the original
STL's end caps are outside the simulated fluid segment.

## Regenerate without replacing the prepared pair

With the geometry and Python tools installed and their environment active:

```sh
hlb-gmy-cli first-run.pr2 --geometry regenerated.gmy --xml generated.xml
hlb-gmy-selfconsistent regenerated.gmy
```

Always use the newly generated XML with the regenerated GMY. Copy the
`<simulation><checkpoint period="100" /></simulation>` request and the
`<properties>` section from `first-run.xml` into it to enable field output, as
shown in the [walkthrough](../doc/user/getting-started.md#regenerate-the-case-from-stl).
A later library version or changed profile may generate a different lattice;
the new XML carries the corresponding origin and voxel size.
