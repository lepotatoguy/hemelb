# Geometry generation tool

Generate a voxelised `.gmy` geometry and XML configuration from an STL
surface and a saved profile. `hlb-gmy-gui` edits profiles; `hlb-gmy-cli`
generates geometry without a window.

[Install and use the tool](../doc/user/geometry-tool.md),
[first-run workflow](../doc/user/getting-started.md), and
[test instructions](../doc/dev/README.md#geometry-and-analysis-tools).
